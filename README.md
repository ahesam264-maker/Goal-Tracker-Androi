# Goal Tracker — مسیر (نسخه اندروید)

اپلیکیشن مدیریت اهداف و مسیر پیشرفت؛ همان پروژه وب قبلی حالا با **نسخه اندروید قابل نصب (APK)**، **تایمر در پس‌زمینه**، **اعلان‌های زمان‌بندی‌شده**، **فونت محلی وزیرمتن** و **آیکون اختصاصی**.

---

## ۱) قابلیت‌های برنامه

| بخش | توضیح |
|---|---|
| ساخت هدف | نام، توضیح، تعداد روز، تاریخ شروع شمسی، آیکون اختیاری |
| مسیر پیشرفت | جاده گرافیکی پویا؛ هر مرحله = یک روز چالش |
| صفحه هر روز | وظایف (افزودن/ویرایش/حذف/ساعت)، ۵ یادداشت هدایت‌شده، ارزیابی ستاره‌ای، ثبت و تکمیل روز |
| ابزارهای تمرکز | پومودورو، مدیتیشن، کار عمیق، ۶ تمرین ضد حواس‌پرتی |
| هشدار صوتی | تولیدشده با Web Audio API؛ بدون فایل صوتی |
| آرشیو و گزارش‌ها | آمار، نمودار روند، گزارش کلی مسیر |
| پشتیبان‌گیری | JSON کامل / هر مسیر / هر روز + واردکردن پشتیبان |
| خروجی PDF | چاپ A4 آبی‌وسفید با CSS Print |
| **اعلان‌های زمان‌بندی‌شده** | ساخت/ویرایش/حذف با تاریخ و ساعت شمسی؛ نمایش بومی با AlarmManager |
| **تایمر پس‌زمینه** | Foreground Service + اعلان دائمی با دکمه‌های Pause / Play / X |
| **آفلاین** | همه امکانات اصلی بدون اینترنت در APK کار می‌کنند |

## ۳) چگونه Repository بسازیم و فایل‌ها را بگذاریم

1. در GitHub گزینه **New repository** را بزنید.
2. نام مخزن: `Goal-Tracker-Android` (عمومی یا خصوصی).
3. **README اضافه نکنید** (فایل README.md از پروژه می‌آید).
4. در پوشه پروژه اجرا کنید:
```bash
git init
git add .
git commit -m "Goal Tracker: web + android + CI"
git branch -M main
git remote add https://github.com/<YOUR-USER>/Goal-Tracker-Android.git
git push -u origin main
```

## ۴) فعال‌سازی GitHub Pages (نسخه وب)

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `main` / `/ (root)`
4. ذخیره کنید؛ چند ثانیه بعد آدرس زیر فعال می‌شود:
`https://<YOUR-USER>.github.io/Goal-Tracker-Android/`

---

## ۵) ساخت APK

1. در مخزن: **Actions** → **Android APK Build** → **Run workflow**.
2. پس از پایان سبز، بخش **Artifacts**:
   - `Goal-Tracker-debug-APK` ← نسخه قابل نصب
   - `Goal-Tracker-release-APK` ← نسخه Release
3. فایل ZIP را دانلود و `app-debug.apk` را روی گوشی باز کنید.

**امضای Release:** این Secrets را در Settings → Secrets and variables → Actions تعریف کنید:
`RELEASE_KEYSTORE_BASE64` (base64 فایل jks)، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`

---

## ۶) نصب روی گوشی و مجوزها

1. فایل APK را در گوشی باز کنید و «نصب» را بزنید (لازم است «نصب از منابع ناشناس» برای مرورگر/فایل‌منیجر مجاز شود).
2. هنگام اولین اجرا، مجوز **اعلان‌ها** را بپذیرید.
3. در برنامه → بخش «اعلان‌ها» → دکمه «اجازه اعلان‌ها» و «اعلان دقیق ساعت» را بزنید.
4. برای اطمینان از اجرای تایمر در پس‌زمینه: تنظیمات گوشی → باتری → برنامه‌ها → Goal Tracker → «بدون محدودیت» (نام در بعضی گوشی‌ها «محدودیت باتری بی‌شمر» است).

---

## ۷) محدودیت‌های صادقانه

- **Force Stop** یا پاک‌کردن اجباری برنامه توسط سیستم/کاربر، سرویس تایمر را متوقف می‌کند؛ هیچ اپی این را تضمین نمی‌کند.
- برخی گوشی‌های چینی (Xiaomi, Huawei, Oppo…) پس از بستن اخیر برنامه، سرویس‌ها را می‌کشند؛ در تنظیمات باتری باید استثنا شود.
- اعلان دقیق (setExact) به دسترسی «SCHEDULE_EXACT_ALARM» نیاز دارد؛ در صورت نبود، زمان‌بندی تقریبی انجام می‌شود.
- در **نسخه وب**، اعلان زمان‌بندی‌شده فقط وقتی صفحه باز است کار می‌کند (یا باید از Notification مرورگر استفاده شود). نسخه APK این محدودیت را ندارد.
- فایل‌های woff2 فونت در مخزن موجود نیستند (دودوئل باینری)؛ مرحله ساخت CI آن‌ها را دانلود می‌کند یا می‌توانید دستی در `assets/fonts/` بگذارید.
- آیکون لانچر به‌صورت **Vector/Adaptive** تعریف شده (minSdk 26)؛ نسخه PNG فقط در صورت نیاز از `assets/icons/icon.svg` ساخته می‌شود.
